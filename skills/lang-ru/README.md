# Pack: Russian market (lang-ru)

Shipping software to the Russian-language market. Written **in English about Russian**: plural and gendered forms, tone that does not survive translation, job-application norms, and bilingual product architecture.

## Skills

- [`ru-ui-strings`](ru-ui-strings/SKILL.md)
- [`ru-en-tone-transfer`](ru-en-tone-transfer/SKILL.md)
- [`ru-market-job-application-norms`](ru-market-job-application-norms/SKILL.md)
- [`bilingual-product-architecture`](bilingual-product-architecture/SKILL.md)

## Expects

Nothing.

## Soft companions

`frontend`, `writing` — companions are suggestions, not requirements. Every skill here works with the
companion pack absent; cross-pack references are written to degrade gracefully.

## Notes

Russian appears only as data — examples in guillemets and code blocks. Install alongside `frontend` (i18n) or `writing` (copy) depending on what you are building.

Do not install this pack unless the product actually ships Russian content.

---

Install: `/plugin install lang-ru@engineering-skills`, or
`./scripts/install.sh <project> --packs lang-ru`, or ask your agent to install the
**lang-ru** pack from `glotyuids/engineering-skills`.
