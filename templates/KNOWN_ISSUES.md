# Known issues

A living list of confirmed gaps and open follow-ups. **This is not a roadmap** — it is the
honest current state, so nobody (human or agent) assumes something works because it was
written down somewhere.

Each entry: what the symptom is → what is actually true today → the resolution path, and
whether that path has been executed.

Prefixes:

- `Verify:` — believed true but never confirmed by running it.
- `Not an issue:` — looks wrong, is deliberate; recorded so it stops being re-reported.
